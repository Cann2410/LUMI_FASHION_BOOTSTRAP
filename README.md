# LUMI FASHION – Bootstrap 5

Website thời trang nữ được xây dựng bằng **Bootstrap 5 framework**, kết hợp HTML5, CSS3 và JavaScript.

## Cấu trúc
- `index.html`: giao diện website và Bootstrap components.
- `css/style.css`: CSS tùy chỉnh cho màu sắc, typography và hiệu ứng.
- `js/script.js`: tương tác nút sản phẩm và form liên hệ.
- `WIRE_FRAMES.txt`: bộ wireframe Desktop/Mobile.

## Bootstrap được sử dụng
- Responsive Navbar và menu mobile.
- Container, Row, Column cho bố cục responsive.
- Card và Grid cho danh sách sản phẩm.
- Button và Form controls cho tương tác.
- Utility classes như `d-flex`, `gap`, `shadow`, `rounded`, `py-*`, `mb-*`.

## 4 tính năng bổ sung
1. Responsive Design.
2. Product Listing.
3. Product Interaction bằng JavaScript.
4. Contact Form có kiểm tra dữ liệu và thông báo.

## Chạy website
Mở `index.html` bằng trình duyệt hoặc triển khai thư mục này lên GitHub Pages.
